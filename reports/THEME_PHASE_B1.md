## Theme Foundation

- `:root` light palette from the plan, using sage accent `#5B7568`
- `[data-theme="dark"]` dark palette from the plan, using sage accent `#8FB3A2`
- all `--color-*` properties from the plan
- all `--shadow-*` properties from the plan
- RGB channel companions for every color token, e.g. `--rgb-primary`

Imported it immediately after variables in `sass/main.scss`:

```scss

@import 'abstracts/theme-properties';
```

Aliased all 20 global color `$uy-*` tokens in `sass/abstracts/_variables.scss` to `var(--color-...)`. Shadow tokens now alias to `var(--shadow-...)`.

- reads `localStorage` key `uy-theme`
- falls back to `prefers-color-scheme` on first visit
- writes `document.documentElement.dataset.theme`
- flips between `light` and `dark`
- updates `aria-label`, `aria-pressed`, and visually hidden label text
- persists explicit user choice to `localStorage`
